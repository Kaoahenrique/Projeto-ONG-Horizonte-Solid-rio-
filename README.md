## 🧭 Sobre o Projeto  

O **Horizonte Solidário** é um site institucional de uma ONG fictícia desenvolvido para fins acadêmicos, com o objetivo de aplicar os conceitos fundamentais de **HTML, CSS e JavaScript**.  

---

## 📂 Estrutura das Atividades  

| Etapa | Descrição |
|:------|:-----------|
| **Atividade I** | Estruturação básica em HTML (páginas: *index*, *cadastro*, *projetos*) |
| **Atividade II** | Aplicação de CSS, responsividade e organização em pastas (`css/`, `js/`, `assets/`) |
| **Atividade III** | Implementação de interações com JavaScript (*menu mobile, modal e toast*) |
| **Atividade IV** | Publicação, validação e finalização do site no GitHub Pages |

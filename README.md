## 🧭 Sobre o Projeto  

O **Horizonte Solidário** é um site institucional de uma ONG fictícia desenvolvido para fins acadêmicos, com o objetivo de aplicar os fundamentos de **HTML5**, **CSS3** e **JavaScript**, simulando o processo real de criação de um website profissional.  

O projeto integra **design responsivo, interações dinâmicas** e **organização modular**, reforçando boas práticas de estrutura e código limpo.  

---

## 📂 Estrutura das Atividades  

| Etapa | Descrição |
|:------|:-----------|
| **Atividade I** | Estruturação básica em HTML (páginas: *index*, *cadastro*, *projetos*) |
| **Atividade II** | Aplicação de **CSS3**, responsividade e organização em pastas (`css/`, `js/`, `assets/`) |
| **Atividade III** | Implementação de **JavaScript modular** (*menu mobile funcional, modal e toast de interação*) |
| **Atividade IV** | Publicação e validação final do site no **GitHub Pages** |

## 🧠 Conceitos Aplicados  

- Manipulação do **DOM** e eventos  
- Sistema de **menu mobile funcional** com JavaScript  
- Modal de doação e **notificações interativas (toast)**  
- **Validação de formulários** com feedback visual  
- Organização modular em **HTML, CSS e JS**  
- Design **responsivo e acessível** (Mobile First)  

---

## 🧩 Tecnologias Utilizadas  

- **HTML5** — Estrutura semântica e acessível  
- **CSS3** — Flexbox, Grid, variáveis e responsividade  
- **JavaScript** — Interatividade, DOM e SPA simplificada  
- **Font Awesome** — Ícones vetoriais  
- **GitHub Pages** — Hospedagem gratuita
